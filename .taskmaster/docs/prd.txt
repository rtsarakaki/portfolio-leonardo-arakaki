# Product Requirement Document (PRD) – Site Portfólio Leonardo Franco Arakaki

## 1. Visão Geral do Projeto

### Objetivo
Criar um site portfólio profissional em Next.js com TailwindCSS para apresentar o perfil, experiências, projetos e formação de Leonardo Franco Arakaki, estudante de Arquitetura e Urbanismo na FAUUSP.

### Propósito
- Servir como portfólio profissional para atrair recrutadores
- Apresentar projetos de arquitetura e design
- Demonstrar competências em idiomas para oportunidades de ensino
- Estabelecer presença digital profissional

## 2. User Personas

### Persona 1: Recrutadores de Empresas
- **Perfil**: Recrutadores de empresas de arquitetura/design
- **Objetivo**: Encontrar candidatos com boa formação acadêmica e experiência prática
- **Necessidades**: Visualizar projetos, experiência e formação acadêmica

### Persona 2: Escritórios Independentes
- **Perfil**: Escritórios de arquitetura e design independentes
- **Objetivo**: Identificar talentos para projetos específicos
- **Necessidades**: Portfólio de projetos e habilidades técnicas

### Persona 3: Alunos de Inglês
- **Perfil**: Escolas e alunos interessados em aulas de inglês
- **Objetivo**: Encontrar professor qualificado
- **Necessidades**: Informações sobre certificações e experiência em ensino

## 3. Especificações Técnicas

### Stack Tecnológica
- **Framework**: Next.js 14+ (App Router)
- **Styling**: TailwindCSS
- **Linguagem**: TypeScript
- **Deploy**: Vercel
- **Versionamento**: Git/GitHub

### Requisitos Técnicos
- Design responsivo (mobile-first)
- Performance otimizada (Core Web Vitals)
- SEO básico implementado
- Acessibilidade (WCAG 2.1 AA)
- Loading states e animações suaves

## 5. Design e UX

### Princípios de Design
- **Minimalista**: Foco no conteúdo, sem elementos desnecessários
- **Limpo**: Tipografia clara e espaçamento adequado
- **Profissional**: Paleta de cores neutra e elegante

### Paleta de Cores
- **Primária**: Tons neutros (branco, cinza, preto)
- **Destaque**: Azul ou verde (inspirado em arquitetura)
- **Acessibilidade**: Contraste adequado para leitura

### Layout
- **Responsivo**: Desktop, tablet e mobile
- **Cards**: Cada seção em card com título em destaque
- **Navegação**: Navbar fixa com links para seções
- **Footer**: Informações de contato

## 6. Funcionalidades

### Navegação
- Menu de navegação responsivo
- Links internos para seções
- Scroll suave entre seções

### Responsividade
- Mobile-first design
- Breakpoints: sm (640px), md (768px), lg (1024px), xl (1280px)
- Imagens otimizadas para diferentes dispositivos

### Performance
- Lazy loading de imagens
- Otimização de fontes
- Bundle size otimizado
