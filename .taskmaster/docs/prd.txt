# Product Requirement Document (PRD) – Portfólio Arquitetônico Interativo Leonardo Arakaki

## 1. Visão Geral do Projeto

### Objetivo
Criar um portfólio arquitetônico interativo em Next.js com design inspirado em croquis arquitetônicos, utilizando sistema de navegação dinâmica com "cotas arquiteturais" e animações de expansão direcionais.

### Conceito Visual
- **Estética**: Croqui arquitetônico com linhas rusticas e estilo desenhado à mão
- **Navegação**: Sistema de cotas arquiteturais que indicam direção de expansão
- **Tipografia**: Nome "Leonardo Arakaki" em estilo caligrafia oriental/japonesa customizada
- **Interatividade**: Animações de expansão baseadas na posição das cotas

## 2. User Stories - Epic 1: Sistema de Navegação Arquitetônica

### US-001: Navegação Principal com Cotas
**Como** um visitante do portfólio  
**Quero** navegar entre seções usando um sistema visual inspirado em desenhos arquitetônicos  
**Para que** eu tenha uma experiência única e memorável

**Critérios de Aceitação:**
- [ ] Menu principal com 4 seções: Perfil, Experiências, Formação, Projetos
- [ ] Cada seção possui uma "cota arquitetônica" indicando direção de expansão
- [ ] Cotas são linhas tracejadas rusticas na cor #8B4513
- [ ] Posicionamento das cotas: Perfil (lateral esquerda), Experiências (inferior), Formação (lateral direita), Projetos (superior)

### US-002: Animações de Expansão Direcionais
**Como** um usuário interagindo com o portfólio  
**Quero** que as seções se expandam na direção indicada pela cota  
**Para que** eu entenda visualmente o fluxo de navegação

**Critérios de Aceitação:**
- [ ] Perfil: expansão da esquerda para direita (cota lateral esquerda)
- [ ] Experiências: expansão de baixo para cima (cota inferior)
- [ ] Formação: expansão da direita para esquerda (cota lateral direita)
- [ ] Projetos: expansão de cima para baixo (cota superior)
- [ ] Duração da animação: 0.6s com easing cubic-bezier(0.4, 0, 0.2, 1)
- [ ] Apenas uma seção pode estar expandida por vez

## 3. User Stories - Epic 2: Tipografia Customizada

### US-003: Nome em Caligrafia Oriental
**Como** um visitante do portfólio  
**Quero** ver o nome "Leonardo Arakaki" em estilo caligrafia japonesa customizada  
**Para que** eu tenha uma primeira impressão impactante e única

**Critérios de Aceitação:**
- [ ] Nome renderizado em SVG com traços de pincel
- [ ] Estilo caligrafia oriental/japonesa
- [ ] Cor #8B4513 (marrom arquitetônico)
- [ ] Stroke-width: 6px (negrito)
- [ ] Transform: skewX(-8) (itálico sutil)
- [ ] Espaçamento vertical: 25px entre "Leonardo" e "Arakaki"
- [ ] Dimensões idênticas: 45px altura para ambos os nomes

### US-004: Responsividade da Tipografia
**Como** um usuário em diferentes dispositivos  
**Quero** que o nome mantenha proporções adequadas  
**Para que** eu tenha boa legibilidade em qualquer tela

**Critérios de Aceitação:**
- [ ] Escala proporcional em mobile (70% do tamanho desktop)
- [ ] Escala proporcional em tablet (85% do tamanho desktop)
- [ ] Mantém proporções de stroke e espaçamento
- [ ] ViewBox SVG responsivo

## 6. User Stories - Epic 5: Interatividade e Animações

### US-011: Sistema de Estados
**Como** um usuário interagindo com o portfólio  
**Quero** que o sistema gerencie corretamente os estados das seções  
**Para que** eu tenha uma experiência fluida

**Critérios de Aceitação:**
- [ ] Estado inicial: apenas navegação visível
- [ ] Estado expandido: seção ativa com conteúdo
- [ ] Transição entre seções: fechar atual, abrir nova
- [ ] Estado de loading durante transições
- [ ] Persistência do estado durante navegação

### US-012: Animações de Transição
**Como** um usuário navegando entre seções  
**Quero** ver animações suaves e elegantes  
**Para que** eu tenha uma experiência premium

**Critérios de Aceitação:**
- [ ] Animações CSS com transform e opacity
- [ ] Duração: 0.6s com easing suave
- [ ] Direção baseada na posição da cota
- [ ] Animações de entrada e saída
- [ ] Performance otimizada (60fps)

## 8. Especificações Técnicas

### Stack Tecnológica
- **Framework**: Next.js 14+ (App Router)
- **Styling**: TailwindCSS + CSS customizado
- **Linguagem**: TypeScript
- **Animações**: CSS Transitions + Framer Motion (se necessário)
- **SVG**: Custom para tipografia
- **Deploy**: Vercel
